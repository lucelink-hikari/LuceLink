# LuceLink 機能と制限

**バージョン 3.0**

LuceLinkの機能を紹介します。手順は [マニュアル](MANUAL.md) を参照してください。

| 機能 | できること・注意点 |
| --- | --- |
| 通常チャット | OpenAI・Anthropic・Google・xAIの公式APIとOpenRouterに対応しています。利用できる接続先はサービスとモデルによって異なります。OpenAI公式とOpenRouterでは、ChatGPTの最新Instantモデルを使う「ChatGPT Latest」も選べます。3.0ではLocal AIは廃止しています。画像入力に対応したモデルへJPEG画像を添付できます。中断（Stop）・再試行（Retry）、吹き出し全体とコードブロック単位のコピーにも対応しています。 |
| 履歴・お気に入り | 会話のタイトルや、ご自身・パートナーの発言を検索し、該当する発言へ移動できます。ChatGPT／Claudeから取り込んでLuceLinkに保存した会話も対象です。保存前のExport閲覧画面は、これらの履歴とは別に管理されます。 |
| Recall・会話引き継ぎ | 現在の会話をもとに、会話を続けるためのまとめを作ります。実行時は選択したAIサービスを使います。 |
| メモ・日記 | チャットで選んだ発言を、スレッド式のメモ（Memos）に保存できます。日記は利用者が生成を選んだときに、現在のパートナーとの会話をもとに作成します。内容を確認・編集し、保存するかどうかを選べます。 |
| カスタム | System Prompt、Memory、Additional Memory、Knowledge Fileを管理できます。カスタム設定ごとに使用モデル1／2／3を保存し、チャット上部で切り替えられます。なかよしさん、お兄ちゃん、ルーチェ、おえかきさんのプリセットも収録しています。Knowledge Fileは送信設定に従って送られます。 |
| Web検索（ベータ） | 通常チャットでOpenRouterを使うときに、利用者がONにすると利用できます。AIが必要と判断した場合に、1返信あたり最大1回検索し、最大3件の結果を参照します。検索語がOpenRouter経由でExaへ送られ、追加費用が生じる場合があります。本文中のURLをLuceLinkが直接開く処理とは別です。 |
| Atelier | OpenRouterの画像生成モデルを検索できます。参考画像は最大1枚、モデルごとに条件があります。おえかきさんのON/OFFにかかわらず制作依頼は4,000文字までです。制作依頼をメモに保存したり、メモから呼び出したりできます。最近の生成画像5枚を端末に保存する機能にも対応しています。 |
| ウォーターマーク | チャット画面に表示する透かしの濃度は0〜60%で、未設定時は10%です。画像用ツールは端末画像・Atelierから引き継いだ画像に文字の透かしを加え、別ファイルを出力します。 |
| テーマ・マイルーム | 初期登録24件と、個別のJSONファイルを読み込んで使う任意追加51件のテーマがあります。追加テーマは同時に20件まで登録できます。マイルームの背景画像フィルターは白・黒・なしで、白・黒の吹き出し設定とは別です。 |
| 外観 | アイコンと起動画面は、白〜クリームとシャンパンゴールドのデザインです。専用フォントは、見出しの英数字にLuceLink Jost、本文と日本語にLuceLink Noto Sans JPを使います。 |
| Backup／移行 | 会話、設定、お気に入り（Favorites）、メモ（Memos）、ユーザーテーマなどをZIPでバックアップできます。マイルームの背景画像を含めるかどうかは、書き出すときに選べます。ChatGPT／Claudeの取込、SAIVerse互換データの入出力、Nexus Ark向けMarkdown出力と月別RAWログ（TXT）の取り込みがあります。取り込む前に話者と発言の区切りを確認できます。 |
| PWA・端末保存 | HTTPSのPagesで利用します。ホーム画面からの起動、再読み込み、復元、保存・共有は手元のiPhoneやブラウザでの最終確認が必要です。 |

モデルや経路によって、出力上限と画像入力・Temperatureの扱いが異なります。詳しくは [モデル一覧](MODEL-LIST.md) をご覧ください。テーマの分類は [テーマ一覧](THEME-LIST.md) を参照してください。
