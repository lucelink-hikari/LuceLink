# LuceLink 3.0 機能と制限

LuceLink 3.0の機能を紹介します。手順は [マニュアル](MANUAL.md) を参照してください。

| 機能 | できること・注意点 |
| --- | --- |
| 通常チャット | OpenAI・Anthropic・Google・xAIの公式APIとOpenRouter。利用可能な経路はサービスとモデルによって変わります。3.0ではLocal AIは廃止しています。画像入力対応モデルにJPEG添付を送れます。Stop・Retry、吹き出し全体とコードブロック単位のコピーに対応。 |
| 履歴・お気に入り | タイトル・ユーザー／パートナー発言を検索し、該当発言へ移動。LuceLinkに保存したChatGPT／Claude取込履歴も対象。保存前のExport閲覧画面は別管理です。 |
| Recall・会話引き継ぎ | 現在の会話をもとに補助文脈を作成。実行時は選択したAIサービスを使います。 |
| メモ・日記 | チャットから選んだ発言をスレッド式Memosへ保存。日記は利用者の生成操作から、現行パートナーの会話を参照して作成。確認・編集後に利用者が保存します。 |
| カスタム | System Prompt、Memory、Additional Memory、Knowledge File。カスタム設定ごとに使用モデル1／2／3を保存し、チャット上部で切り替えられます。なかよしさん、お兄ちゃん、ルーチェ、おえかきさんの内蔵プリセット。Knowledgeは送信設定に従います。 |
| Web検索（ベータ） | 通常チャットのOpenRouterで明示的にON。AIの判断で1返信最大1検索・3結果。検索語がOpenRouter経由でExaへ送られ、追加費用が生じる場合があります。本文中のURLをLuceLinkが直接開く処理とは別です。 |
| Atelier | OpenRouterの画像生成モデルを検索。参考画像は最大1枚、モデルごとに条件があります。おえかきさんのON/OFFにかかわらず制作依頼は4,000文字。メモへの保存・呼び出し、最近の生成画像5枚の端末保持に対応。 |
| ウォーターマーク | チャットの画面表示用は0〜60%、未設定時10%。画像用ツールは端末画像・Atelierから引き継いだ画像に文字の透かしを加え、別ファイルを出力します。 |
| テーマ・マイルーム | 初期登録24件と、個別JSONで読み込む任意追加51件。追加テーマは同時に20件まで登録できます。マイルームの背景画像フィルターは白・黒・なしで、白・黒の吹き出し設定とは別です。 |
| 外観 | 白〜クリームとシャンパンゴールドの正式アイコン・起動画面。専用フォントは、見出しの英数字にLuceLink Jost、本文と日本語にLuceLink Noto Sans JPを使います。 |
| Backup／移行 | 会話、設定、Favorites、Memos、ユーザーテーマなどをZIPで保全。マイルームの背景画像は書き出し時に選択。ChatGPT／Claudeの取込、SAIVerse互換データの入出力、Nexus Ark向けMarkdown出力があります。Nexus Arkからの取り込みは保留中です。 |
| PWA・端末保存 | HTTPSのPagesで利用します。ホーム画面からの起動、再読み込み、復元、保存・共有は手元のiPhoneやブラウザでの最終確認が必要です。 |

モデルや経路によって、出力上限と画像入力・Temperatureの扱いが異なります。詳しくは [モデル一覧](MODEL-LIST.md)。テーマの分類は [テーマ一覧](THEME-LIST.md) を参照してください。
