# LuceLink 製品仕様書

**バージョン 3.0**  
2026年11月27日版

## 1. LuceLinkについて

LuceLinkは、AIパートナーとの日常の会話を楽しみ、大切な言葉や思い出を残すためのAPIチャットアプリです。

好きなAIサービスやモデルを選び、パートナーの話し方や記憶、会話画面の色や背景を自分好みに設定できます。会話を続けることだけでなく、過去の会話を読み返すこと、メモや日記に残すこと、ほかのアプリから会話を移すことにも対応しています。

| 項目 | 仕様 |
| --- | --- |
| アプリ名 | LuceLink |
| バージョン | 3.0 |
| 形式 | Webアプリ（PWA対応） |
| 利用環境 | スマートフォン・PCのブラウザ。対応する環境ではホーム画面から起動可能 |
| 設置方法 | 利用者自身のCloudflareアカウントにPagesとWorkerを設置 |
| アプリ本体 | 無料配布 |
| AI利用料金 | 利用するAIサービス、モデル、入出力、検索、画像生成等に応じて別途発生する場合あり |
| 保存先 | 利用端末のブラウザ内。端末間の移行にはバックアップを使用 |

LuceLinkはAIモデルそのものを提供するサービスではありません。利用したいAIサービスのAPIキーが必要です。ChatGPTなどの公式アプリの利用契約とは別に、APIの利用条件を確認してください。

## 2. AIサービスとモデル

| 接続先 | 主なモデル系列 |
| --- | --- |
| OpenAI公式API | GPTシリーズ、ChatGPT Latest |
| Anthropic公式API | Claudeシリーズ |
| Google公式API | Geminiシリーズ |
| xAI公式API | Grokシリーズ |
| OpenRouter | 提供中の各社・各種モデル、ChatGPT Latest |

- モデル一覧を取得し、利用するモデルを選択できます。取得できない場合は代表的な代替候補を表示します。
- OpenRouterではモデル名・モデルIDで検索できます。
- カスタムごとに「使用モデル1／2／3」を登録し、チャット画面から切り替えられます。
- ChatGPT Latestは、その時点のChatGPTのInstantモデルを利用するための選択肢です。同じモデル名でも提供元の更新によって応答が変わる場合があります。
- 出力上限、Temperature、画像入力などの対応は、モデルと接続先によって異なります。対応しないパラメーターは送信しない扱いがあります。
- 提供終了が確認されたモデルは新規選択候補から外れます。保存済みのモデル設定は自動で書き換えません。
- Local AIは対象外です。

モデルの提供状況、価格、利用上限は変動します。詳しくは[モデル一覧](https://github.com/lucelink-hikari/LuceLink/blob/main/docs/MODEL-LIST.md)と各AIサービスの案内を参照してください。

## 3. AIパートナーのカスタマイズ

| 機能 | 仕様 |
| --- | --- |
| System Prompt | パートナーの性格や口調、応答方針を設定 |
| Memory | 会話が変わっても伝えておきたい内容を登録 |
| Additional Memory（覚えておいてほしいこと） | 追加の記憶を登録。通常Memoryに内容があり、両方の送信設定が有効なときに送信 |
| Knowledge File | AIに参照させたい資料を登録。送信設定に従って利用 |
| 時間認識 | 有効時に、端末の日付・時刻・タイムゾーンを通常送信・再試行時に伝える |
| 使用モデル | カスタムごとに3つのモデルを登録 |

カスタムの保存・編集・複製に対応します。送信を有効にした記憶や資料は、応答に必要な情報として選択したAIサービスに送られます。資料が長い場合はAPI料金が増えることがあります。

### 内蔵プリセット・専用エージェント

LuceLinkには、次の4人の専門カスタムが内蔵プリセットとして用意されています。利用者が選択して、自分のカスタム設定として保存・利用できます。

| 名称 | 役割・仕様 |
| --- | --- |
| なかよしさん | AIパートナーとの関係を大切にしながら、モデル・サービス間の引っ越し、話し合い用の文面、プロンプト作成・調整、人格や口調の復帰、雑談を支える相談役。5つの相談モードがあり、挨拶・雑談で選択を強制しません |
| お兄ちゃん | 少し不運で気だるく、世話焼きな相談役。日常会話、作業の付き添い、画像制作・プロンプト相談に加え、AIモデル、API、開発、セキュリティ、プライバシーについても相談できます |
| ルーチェ（愛称：るー） | モノクルをかけた紳士ウサギの公式マスコット・総合案内役。設置、接続、設定、各機能の使い方、困ったときの対処をKnowledgeに基づいて案内します |
| おえかきさん | デジタルアーティスト・ビジュアルディレクターの視点で、画風、構図、質感、参考画像、制作意図を尊重する画像制作専門の指示。Atelierにも専用のON／OFFがあります |

なかよしさん・お兄ちゃん・ルーチェには、AIパートナーとの大切な関係や利用者自身の希望を尊重する共通方針と、それぞれのKnowledgeが用意されています。プリセットは自動で既存のカスタムを置き換えるものではありません。Knowledgeを使う場合は資料と送信設定を確認してください。通常チャットのプリセットとAtelierで画像を生成する機能は別です。

内蔵プリセットを選択して保存すると、内蔵プリセット欄から保存済みのカスタム一覧へ移ります。見当たらない場合は、保存済みのカスタム一覧をご確認ください。なかよしさん・お兄ちゃん・ルーチェのKnowledgeは登録時の送信設定がオフです。資料を参照させる場合は、内容を確認してから送信設定をオンにしてください。ルーチェの資料を更新する場合は、保存済みのカスタムのKnowledge Fileも確認してください。

## 4. 会話と履歴

| 機能 | 仕様 |
| --- | --- |
| 通常チャット | 選択したAIモデルとのテキスト会話 |
| 新規会話 | 新しい会話の開始。前の会話を引き継ぐか、まっさらで始めるかを選択 |
| Stop／Retry | 返信生成の中断・再試行 |
| 履歴 | 過去の会話を保存・閲覧 |
| 履歴検索 | 会話タイトル、利用者・AI双方の発言を検索し、該当発言へ移動 |
| コピー | AIの吹き出し全体、またはコードブロック単位でコピー |
| モデル名・時刻 | 常時表示の切り替え。非表示時も長押しで確認 |
| 画像添付 | 対応モデルへJPEG画像を1枚送信。圧縮後2MBまで |
| テキスト添付 | UTF-8のTXT・MD・JSON・CSV。1ファイル240 KiBまで |

送信画像そのものや添付テキストファイルの本文は、会話履歴・ZIPバックアップには保存されません。テキストファイルの本文は添付して送った回のみAIに渡り、次の発言には自動で送られません。元のファイルは別に保管してください。

中断してもすでに発生したAPI料金が取り消されるとは限りません。再試行にも料金がかかる場合があります。

### Web検索（ベータ）

通常チャットでOpenRouterを利用しているときに、利用者が有効にすると使えます。AIが必要と判断した場合に1返信につき最大1回検索し、最大3件の検索結果を参照します。検索語はOpenRouter経由でExaに送られます。検索料金が別途発生する場合があります。

## 5. 会話の継続・思い出の管理

| 機能 | 仕様 |
| --- | --- |
| 会話引き継ぎ（Continuity） | 現在の会話をまとめ、新しい会話に引き継ぐ補助情報として保存。元会話やMemoryは変更しない |
| 思い出す（Recall） | 現在の会話にあるAI側の発言を読み返してまとめる。成功した場合に更新し、通常の会話欄には要約を追加しない |
| お気に入り（Favorites） | 大切な発言を登録し、見返す |
| メモ（Memos） | カテゴリ・スレッド・投稿で文章を整理。会話から選んだ発言を保存 |
| 日記 | 現在のパートナーとの会話をもとに日記を作成。生成した文章を確認・編集し、選択した場合のみメモに保存 |

会話引き継ぎ・Recall・日記は、選択したAIサービスを使用する機能です。すべての過去の会話や長期記憶を自動的に読み込む機能ではありません。

## 6. テーマとマイルーム

### テーマ（全75種類）

| 区分 | 内容 | 数 |
| --- | --- | ---: |
| 初期登録 | 標準テーマ | 18 |
| 初期登録 | 基本6色のポルカドット壁紙付きテーマ | 6 |
| 任意追加 | 配色テーマ | 29 |
| 任意追加 | 装飾・配色テーマ（Crystal Blue、Crystal Gold、Sakura Pink、Slate） | 4 |
| 任意追加 | 基本6色のアーガイル・ギンガム・コスメラメ壁紙付きテーマ | 18 |
| 合計 | 初期24種＋任意追加51種 | 75 |

初期表示はSoft White。基本6色はSky、Peach、Apricot、Honey、Matcha、Lilacです。ポルカドットと3種類の壁紙違いを合わせて24枚の壁紙を収録しています。

任意追加テーマは配布ZIPに含まれるJSONを選んで読み込みます。自作テーマも同じ形式で追加できます。

- テーマ形式：`lucelink-theme.v1`
- 読み込み上限：1ファイル200,000バイト
- 同時追加登録：20件まで（初期登録24件は含まない）
- 同じ名前のテーマを追加した場合は別名で登録し、元のテーマを維持します。

全テーマの名前とファイル名は[テーマ一覧](https://github.com/lucelink-hikari/LuceLink/blob/main/docs/THEME-LIST.md)で確認できます。

### マイルーム

好きな画像を背景にして、会話する部屋を自分好みに設定できます。

| 項目 | 仕様 |
| --- | --- |
| 部屋 | 最大10部屋保存 |
| 背景画像 | 端末内に保存。AIサービスやWorkerへ送信しない |
| 背景フィルター | 白・黒・なし |
| 吹き出し | 白・黒の濃さと不透明度を個別調整 |
| バックアップ | 背景画像を含めるかどうかを選択可能 |

### 外観・撮影用機能

- 白からクリーム、シャンパンゴールドを基調としたアイコンと起動画面。
- 専用フォント：LuceLink Jost、LuceLink Noto Sans JP。
- 撮影用の伏せ字：呼び名・秘密語・会話本文を画面上で隠す。保存した文章は変更しません。
- チャット透かし：文字を画面に繰り返し表示。100文字まで、濃度0〜60％（初期10％）。会話本文やコピー・AI送信内容には影響しません。

## 7. Atelier（アトリエ）・画像ツール

Atelierは、通常チャットとは独立した画像生成機能です。OpenRouterの画像生成モデルを利用します。

| 項目 | 仕様 |
| --- | --- |
| 接続先 | OpenRouter |
| モデル | 画像生成モデルの取得・検索・選択 |
| 制作依頼 | 4,000文字まで（おえかきさんON／OFF共通） |
| おえかきさん | 画像制作向けの専用指示を利用するON／OFF設定 |
| 参考画像 | 最大1枚。必要・任意・非対応など、モデルごとの条件に従う |
| 制作メモ | 制作依頼をメモへ保存、メモから呼び出し |
| 生成画像の履歴 | 端末に最近の5枚を保存 |
| 画像の保存 | 写真・ファイルとして個別保存。端末によって保存方法が異なる |

画像生成モデルによって生成可能な内容や参考画像の扱い、料金が異なります。参考画像を2枚以上必須とするモデルは候補に表示されません。

### ウォーターマーク

端末内の画像やAtelierで生成した画像に、文字の透かしを加える独立した画像ツールです。プレビューを確認して別ファイルとして保存できます。元の画像を上書きしません。

チャット画面の透かしとは別の機能であり、画像生成APIによる編集機能でもありません。

## 8. 他のアプリとの会話連携

LuceLinkでは、ほかのサービス・アプリから大切な会話を移したり、対応形式で書き出したりできます。

| サービス・アプリ | LuceLinkへ取り込み | LuceLinkから書き出し |
| --- | --- | --- |
| ChatGPT | 公式エクスポートの会話データ | 専用の逆方向連携は対象外 |
| Claude | 公式エクスポートの会話データ | 専用の逆方向連携は対象外 |
| SAIVerse | persona-pack内のChatGPT互換JSON、または同JSON単体 | 互換role/content JSON（1会話1ファイル） |
| Nexus Ark | 本体の月別RAWログ（TXT） | お出かけ用Markdown（UTF-8） |

SAIVerseとNexus Arkは、入出力の両方に対応する会話連携です。外部アプリの人格・Memory・設定を丸ごと同期する機能ではありません。

### Nexus Arkからの取り込み

- 同じルームの月別RAWログ（YYYY-MM.txt）を複数選択できます。
- USER／AGENTの話者、本文、発言順を取り込みます。
- プレビューで発言の区切りを確認し、本文に含まれる見出しの修正や対象発言の除外ができます。
- 確認した月の会話を、既存履歴を残して新しいスレッドとして追加します。
- 1スレッド300発言まで。超えた場合は分割します。全体の上限は500スレッドです。
- 同一内容のファイルは重複して追加されません。期間の重複を自動で統合することはありません。
- 日時がない場合は「日時不明」。タイムゾーンのない日時は元の現地時刻として扱います。

お出かけ用Markdown、Liteの帰宅用JSON、履歴APIからの取り込みは対象外です。添付ファイル本体、内部思考、人格、記憶、設定も取り込みません。

月別RAWログの取り込みはPC版Chromeで合成ログを使って確認しています。Nexus Arkの実利用ログやiPhoneでの操作は未確認です。

## 9. バックアップとデータ管理

### ZIPバックアップ

| 対象 | 取り扱い |
| --- | --- |
| 会話・履歴 | バックアップ対象 |
| 設定・カスタム | バックアップ対象 |
| Memory・追加記憶・Knowledge | バックアップ対象 |
| 会話引き継ぎ・Recall | バックアップ対象 |
| お気に入り・メモ | バックアップ対象 |
| 読み込んだユーザーテーマ | バックアップ対象 |
| マイルーム背景画像 | 書き出し時に含めるか選択 |
| Atelierの生成画像・履歴・参考画像 | 対象外。個別保存 |
| チャットの送信画像・添付ファイル本文 | 対象外。原本を別に保管 |
| 配布テーマ・ツールの原本 | 別に保管 |

ZIPの上限は全体128 MiB、4,096項目、展開後1項目128 MiB・合計160 MiBです。

復元には「会話だけ」「設定だけ」「会話と設定を復元」の選択肢があります。復元は現在のデータを置き換える場合があります。外部アプリからの会話追加とは異なります。

背景画像なしのZIPで設定を復元する場合は、同じ部屋IDがあるときに端末の画像を引き継ぎます。引き継ぎに必要な画像がない、または読み出せない場合はデータ変更前に復元を中止します。

端末・ブラウザ・URLの変更、ブラウザデータ削除の前には、最新のバックアップを保存してください。

配布ZIPの `app/tools/` に、ブラウザで使える独立HTMLツールを3本収録しています。

| ツール | 用途 | ファイル名 |
| --- | --- | --- |
| Theme Maker（スマホ向け） | 色・透明度を調整し、自作テーマのJSONを作成 | `LuceLink-Theme-Maker.html` |
| Theme Maker（PC向け） | PC向けの操作画面で自作テーマのJSONを作成 | `LuceLink-Theme-Maker-PC.html` |

Theme Makerで書き出したJSONはLuceLinkへ読み込めます。簡易プレビューは内蔵テーマの装飾を完全に再現するものではありません。会話を分割するときは元のエクスポートファイルを保管してください。

## 11. 設置・通信・プライバシー

LuceLinkは利用者自身のCloudflare環境に設置するアプリです。Pagesが画面を配信し、WorkerがAIサービスとの通信を担当します。同じバージョンのPages用ファイルとWorkerを使用します。

- Workerのアクセス保護にトークンを使用し、APIキーとトークンをSecretとして管理します。
- 設定・会話・メモ等は端末のブラウザに保存します。ただし応答や画像生成に必要な入力は、Workerを通して選択したAIサービスへ送信します。
- OpenRouterを使う場合、接続先のAIサービスでも入力が処理される場合があります。
- 各AIサービスのデータ保管、学習利用、料金の条件は利用前に確認してください。
- マイルームの背景画像はAI通信に使用しません。
- 診断画面では、アプリ・Workerの版、接続状態、APIキーの登録有無を確認できます。

### AIエージェントによる設置支援

利用者向けの設置ガイドに加え、AIエージェントが導入を支援するための案内を用意しています。対応するエージェントにGitHubリポジトリのURLを渡し、設置ガイドに沿って導入を手伝ってもらうことができます。

実行可能な操作はエージェントの機能や権限によって異なります。Cloudflareへのログイン、権限の承認、Secretの入力は利用者自身が行います。この設置支援と、アプリ内で使うルーチェは別のものです。

## 12. 対応環境と確認範囲

スマートフォン・PCのブラウザで使用するアプリです。ホーム画面からの起動、画像の保存・共有、ファイルの選択やバックアップの操作は端末・ブラウザに依存します。

作者のiPhoneでの試用記録、PC版Chromeでの検証記録があります。ただし全機能・全モデル・全端末について動作確認を完了したものではありません。Androidの確認範囲も限られています。4人の内蔵プリセットの表示・選択・保存・再読み込み後の保持はChromiumで確認されています。すべてのモデルでのKnowledge送信や応答品質を保証するものではありません。
