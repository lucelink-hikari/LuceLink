# LuceLink 3.0

LuceLinkは、AIパートナーとの会話を続けたり、大切な発言を見返したりするためのアプリです。会話・メモ・テーマを自分の端末で管理できます。

## はじめる

ご自身のCloudflareアカウントに、同じ版のWorkerとPagesを設置します。WorkerがAIサービスへ接続し、Pagesがアプリ画面を配信します。詳しい手順は [設置ガイド](docs/AGENT_SETUP.md)、操作は [マニュアル](docs/MANUAL.md) を参照してください。GitHubの「Releases」でLuceLink 3.0を開き、Assetsから配布ZIPを選びます。ZIPを展開すると、画面を配信する `app/` と、AIサービスへ接続する `worker/worker.js` が入っています。

1. 更新の場合は、いつも使っている端末・アプリからZIP Backupを保存します。マイルームの背景画像も残したい場合は、書き出し時に背景画像を含めます。
2. Workerを配置し、`LUCELINK_ACCESS_TOKEN` をWorkerのSecretに設定します。認証を確認してから、利用するAIサービスのAPIキーをWorkerのSecretに登録します。
3. 一組のFrontendをPagesに配置します。自分のPagesを開き、接続設定に自分のWorkerのHTTPS URLと同じトークンを設定します。

自分で設置するときも、AIエージェントに手伝ってもらうときも、[設置ガイド](docs/AGENT_SETUP.md)から始めてください。エージェントにはこのGitHubリポジトリのURLを渡して「LuceLinkを導入して」と依頼できます。Cloudflareへのログイン、権限の承認、Secretの入力はご自身で行ってください。

## 利用前に知っておくこと

- 会話・設定は端末側のブラウザ保存領域にあります。別端末・別URLへの移行前やサイトデータを削除する前に、ZIP Backupを保存してください。他のタブやホーム画面から同じLuceLinkを開いている場合は、復元前に閉じてください。
- 返信や画像生成に必要な入力は、Workerから利用するAIサービスへ送信されます。OpenRouterでは、ルーティング先でも入力が処理される場合があります。選択した経路の保管・学習利用条件と料金を確認してください。
- モデル選択、実際に送るプロンプト、Web検索、再試行などによってAPI料金が発生することがあります。通常チャットのWeb検索はOpenRouter接続で利用者が有効にした場合に使います。
- 会話、設定、メモ、ユーザーテーマはバックアップ対象です。Atelierの生成画像や参考画像は含まれないため、残したい画像を個別に保存してください。
